# starter-vault/

Empty Obsidian vault skeleton. Participants on **Path A** (Obsidian + Claude Code) or **Path D** (plain markdown + any agent) copy this into their own directory during bootstrap.

Conventions documented in `CLAUDE.md` (and duplicate `AGENTS.md` for non-Claude agents). See `../AGENTS.md` in the repo root for the full story.

## Folders

- `Personal/` -- personal notes, journal
  - `People/` -- profiles (intentionally empty in starter)
- `Projects/` -- active project docs
- `Meetings/` -- meeting notes with action items
- `Learning/` -- book/video/article takeaways
- `Reference/` -- how-to guides, reusable knowledge
- `Notes/` -- atomic ideas, quick captures
- `Templates/` -- Templater-compatible note templates
- `Attachments/` -- images, PDFs
